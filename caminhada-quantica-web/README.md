# Caminhada Quântica — Malha 3×3

Primeira versão da interface web da simulação.

## Rodar

Requer Node.js instalado.

```bash
npm install
npm run dev
```

Depois abra o endereço exibido pelo Vite, normalmente:

http://localhost:5173

## O que já está implementado

- malha 3×3 sem contorno periódico;
- arcos direcionados;
- moeda de Hadamard nos vértices de grau 2;
- moeda de Grover nos vértices de grau 3 e 4;
- deslocamento flip-flop;
- operador U = SC;
- evolução determinística do estado;
- visualização 3D com barras;
- rotação e zoom com mouse;
- anterior / próximo;
- play / pause;
- slider;
- ir diretamente para um passo;
- velocidade da animação;
- estado em notação de Dirac;
- norma do estado;
- soma das probabilidades;
- vértice de maior probabilidade;
- matriz 3×3 de probabilidades.
